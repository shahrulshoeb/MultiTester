Cara tambah dalam KiCad:
1. Preferences > Manage Symbol Libraries > Add existing library: pilih kedua-dua fail dalam symbols.
2. Preferences > Manage Footprint Libraries > Add existing library: pilih folder SENZO_RF.pretty dalam footprints. Gunakan nama library SENZO_RF.
3. Pilih varian footprint yang sesuai dan assign kepada symbol mengikut projek.

Nama, geometri, nombor pin dan pad dikekalkan daripada sumber. Varian OfficialCAD_Review dikekalkan sebagai varian review; kesesuaian untuk pembuatan belum disahkan.
